# square-color 仕様書 & テスト報告書

本ドキュメントは、WordPressのカスタムHTMLブロックとして動作する `square-color`（縦横編み配色・模様シミュレーター）の画面機能、色見本帳（`color-viewer.html`）連携、ブラウザ永続化、外部連携API仕様、および検証結果をまとめたものです。  
全体共通のAPI規約については [`api_specification.md`](../api_specification.md)、WordPress実装規約については [`wordpress_js_guidelines.md`](../wordpress_js_guidelines.md) を参照してください。

---

## 1. 概要・ファイル構成

クラフトバンドの縦横編み（垂直ひも × 編みひも）における織りパターン（上下図）と配色の組み合わせをブラウザ上でシミュレーションし、PDF出力できるツールです。

- **公開URL**: `https://labo.com/CraftBand/sharing/square-color/`
- **ファイル構成**:
  - `square-color.html`: ローカル検証用スタンドアロンHTML（末尾に WordPress 説明ブロック転記用の `[AI / Developer API Reference]` を併記）
  - `square-color-snippet.html`: WordPress「カスタムHTML」ブロック貼付用スニペット（`<!-- wp:html -->` 〜 `<!-- /wp:html -->`、単一コンテナ・危険演算子ゼロ化・実体参照化済み）
  - `square-color.md`: 本仕様書
- **連携先パーツ**:
  - [`../nowp-pages/color-viewer.html`](../nowp-pages/color-viewer.md)（本番: `https://labo.com/CraftBand/nowp-pages/color-viewer.html`、ローカル検証時: `../nowp-pages/color-viewer.html` に自動切替）

## 2. 画面・機能仕様

### 2.1 サイズ指定（折りたたみ）
- **垂直ひも (右へ)**: 初期値 `19` 本（最小 `1`、数値入力および `-10` / `-1` / `+1` / `+10` ボタン）
- **編みひも (下から)**: 初期値 `12` 本（最小 `1`、数値入力および `-10` / `-1` / `+1` / `+10` ボタン）
- 増設されたひもは「現在の色」で初期化され、サイズ変更時に Undo キャッシュはクリアされます。

### 2.2 ひも上下・UpDown編集（折りたたみ）
- **上下図名ドロップダウン**: プリセット6種（およびAPI経由で追加されたカスタムパターン）を選択可能。選択すると `UpDown` テキストボックスへ値がロードされ、Canvasと上下図名表示が即時更新されます。
- **`UpDown` テキストボックス ＋「適用」ボタン**:
  - `0`（編みひもが表）、`1`（垂直ひもが表）、`;`（行区切り、左下 `(0,0)` 起点で周期タイリング）の文字列を直接編集可能。
  - **1文字でも編集すると**、名前との対応が失われるため上下図名（ドロップダウン選択およびCanvasフッターの上下図名）を即座にクリアします。
  - **「適用」クリック時のパース規則**:
    1. `0`, `1`, `;` 以外の文字をすべて削除。
    2. `;` で行分割し、空行（`;;` や末尾 `;` 等）を除外。
    3. 有効行が0行の場合はアラートを表示し、直前のパターンを維持。
    4. 複数行の文字数が異なる場合は、**最短の行の長さ**に合わせて各行を切り揃え。
    5. 正規化後の文字列で `UpDown` テキストボックスを書き換え、Canvasへ反映（Undoキャッシュをクリア）。

#### プリセット上下図一覧
| 上下図名 | UpDown 文字列 |
| :--- | :--- |
| 平編み | `10;01` |
| 網代編み2つ飛び | `1100;0110;0011;1001` |
| 網代編み3つ飛び | `111000;011100;001110;000111;100011;110001` |
| 3x3 2-1 | `110;011;101` |
| 3x3 1-2 | `011;110;101` |
| 花桝網代 | `1110000011;0111000111;0011101110;0001111100;1000111000;0001111100;0011101110;0111000111;1110000011;1100010001` |

### 2.3 現在の色の指定
- **現在の色**: ネイティブカラーピッカー（初期値はパレット色 **C**）。
- **代表色から選ぶ**: 代表14色のドロップダウン。
- **パレットへ複写**: 対象スロット（`A`〜`G`）を選択して「パレットにセット」を押下すると、現在の色を該当スロットへ複写し `localStorage` に保存。
  - 色名は代表色ドロップダウンに一致する色があればその表示名、一致しなければ `#rrggbb` を設定。

### 2.4 色パレット（A〜G）と色見本帳連携
- スロットは上から **`A`, `B`, `C`, `D`, `E`, `F`, `G`** の7枠。
- 各行は `[スロット記号]` `[色ボタン（div）]` `[色名ボックス（div・R/O、長文は末尾 ... 省略）]` で構成（WordPressテーマの `button` 共通スタイルによる色上書きを回避するため `div[role="button"]` ＋ `!important` 背景指定を採用）。
  - **色ボタンのクリック**: そのスロットの色を「現在の色」へ反映。
  - **現在色ハイライト**: 「現在の色」と一致するパレット行（`.palette-item.is-current`）を青枠・背景色・色ボタンのリングで強調表示（スマホ画面で「現在の色」欄がスクロールアウトしていても選択中スロットを判別可能）。
  - **色名ボックスのタップ**: `color-viewer.html` を別ウィンドウで開く（`cb_req_id` と `cb_slot=colorA`〜`colorG` を付与）。
- `color-viewer.html` で色が選択されると、多重返却経路（`postMessage` / `BroadcastChannel` / `storage` イベント、`cb_req_id` で重複排除）で受信し、以下を実行します：
  1. 該当スロットの色・色名を更新し `localStorage` に保存。
  2. 選択した色を **「現在の色」にも即時反映**。

### 2.5 一括色割り当て・Canvas操作・PDF出力
- **一括色割り当て**: 対象（垂直ひも / 編みひも）、開始位置（1始まり）、間隔（`0`＝開始位置のみ、`N`＝N本ごと）を指定して現在色を適用。
- **Canvas操作**:
  - 上下端セル（垂直ひも）・左右端セル（編みひも）・交差セル（表側のひも）をクリックで現在色へ変更。
  - 左上角セル＝垂直ひも全塗り、左下角セル＝編みひも全塗り。
  - **1手戻す（Undo）**: 1段階のキャッシュに対応。
- **ホバープレビュー修飾**: `左右反転` / `上下交換`（0/1反転） / `上下左右` にマウスオーバー中のみプレビュー表示。
- **フッター & PDF出力**: Canvas下部に「上下図名」「日時（`YYYY/MM/DD HH:MM:SS`）」「URL」を描画し、`jsPDF`（CDN）でA4縦/横自動判定の `square-color.pdf` を出力。

## 3. ブラウザ永続化（`localStorage`）と初期値

### 3.1 優先順位と保存仕様
- **保存キー**: `cb_square_color_palette_v1`（スロット `A`〜`G` の `{ hex, name }` をJSON保存）
- **初期ロードの優先順位**: **API（URLパラメータ） > `localStorage` > 初期値**
  - ロード完了時点で確定したパレットA〜Gをそのまま `localStorage` に保存し、以降の手動変更（色見本帳選択・パレットにセット）時も即時保存します。
  - プライベートブラウズ等で `localStorage` が制限されている場合は例外を捕捉して動作を継続します。

### 3.2 パレット初期値とCanvas初期割り当て
| スロット | 初期HEX | 初期色名 | 起動時の役割 |
| :---: | :---: | :--- | :--- |
| **A** | `#ff1493` | 濃いピンク | Canvas **垂直ひも**の初期色 |
| **B** | `#00bfff` | 水色 | Canvas **編みひも**の初期色 |
| **C** | `#0000ff` | 青 | **現在の色**の初期値 |
| **D** | `#8b4513` | 茶 | パレット色 |
| **E** | `#000000` | 黒 | パレット色 |
| **F** | `#ffffff` | 白 | パレット色 |
| **G** | `#808080` | グレー | パレット色 |

## 4. 外部連携 API 仕様（URLクエリパラメータ）

| パラメータ名 | 型 | 説明 | 初期値・フォールバック |
| :--- | :--- | :--- | :--- |
| `cb_model` | 文字列 | モデル識別子（`square-color`）。省略可。指定されていて `square-color` 以外の場合は全APIパラメータをスキップ。 | 省略可 |
| `cb_v` | 整数 ($\ge 1$) | 垂直ひもの本数（横サイズ）。不正値・0以下は無視。 | `19` |
| `cb_h` | 整数 ($\ge 1$) | 編みひもの本数（縦サイズ）。不正値・0以下は無視。 | `12` |
| `cb_updown` | 文字列 | `UpDown` 文字列。パース・正規化（非`01;`除去・空行除外・最短行揃え）のうえ適用し、上下図名ドロップダウンへ追加して選択状態にする。 | `10;01` |
| `cb_updown_name` | 文字列 | 上下図名。`cb_updown` と併用時は追加項目の表示名・Canvasフッター名となる。`cb_updown` ありで本パラメータ省略時は `cb_updown` 正規化文字列（24文字超は末尾 `...` 省略）を使用。`cb_updown` 省略時のみ既存プリセット名と一致すれば該当プリセットを選択。 | `平編み` |
| `cb_colorA` 〜 `cb_colorG` | HEX文字列 | パレット色 A〜G（`#RRGGBB` / `RRGGBB` / 3桁短縮 `#RGB` 許容）。不正値は無視。 | 3.2節参照 |
| `cb_colorA_name` 〜 `cb_colorG_name` | 文字列 | パレット色 A〜G の表示名。省略可（色のみ指定された場合は `#rrggbb` を設定）。 | 3.2節参照 |

#### 呼び出し例
```text
https://labo.com/CraftBand/sharing/square-color/?cb_v=15&cb_h=10&cb_updown=110;011;101&cb_updown_name=カスタム斜め&cb_colorA=d3142d&cb_colorA_name=赤紅&cb_colorB=f5f5dc&cb_colorB_name=ベージュ
```
