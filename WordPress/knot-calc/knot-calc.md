# knot-calc ツール仕様書 & テスト報告書

本ドキュメントは、WordPress上で動作する `knot-calc`（四つ畳み編みサイズ計算ツール・縦横立ち上げ）の個別仕様、計算ロジック、およびテスト検証結果をまとめたものです。
全体共通のAPI規格については、ルートディレクトリの [`api_specification.md`](file:///c:/Users/miho/source/repos/WordPress/api_specification.md) を参照してください。

## 📖 1. ツール固有仕様

### 1.1 基本構造と立ち上げ方式
- **編み方**: 四つ畳み編み（縦横立ち上げ）。
- **コマ寸法とコマ要尺**:
  - **コマ寸法**（出来上がり寸法）: 1コマの正方形の一辺の長さ（初期値: 20.0mm）。
  - **コマ要尺**（ひも消費量）: 1コマ結ぶために消費するバンドひもの長さ（初期値: 60.0mm）。
  - すき間は存在せず、バンド幅は参考値（寸法 $\div 2.236$）として扱われます。
- **比率自動補完**:
  - コマ寸法のみ指定時: $\text{要尺} = \text{寸法} \times (6.43 / 2.236) \approx \text{寸法} \times 2.87567$
  - コマ要尺のみ指定時: $\text{寸法} = \text{要尺} \times (2.236 / 6.43) \approx \text{要尺} \times 0.34774$
- **仕上がりサイズ計算**:
  - 横幅 (cm) $= W \times \text{コマ寸法} / 10$
  - 奥行 (cm) $= D \times \text{コマ寸法} / 10$
  - 高さ (cm) $= H \times \text{コマ寸法} / 10$ （折り返しコマ数 $F$ は含まない）

### 1.2 ブラウザ前回値保存（localStorage）仕様と優先順位
四つ畳み編みのコマ寸法と要尺は、ユーザーの手加減（ゲージ）に強く依存するため、ブラウザに自動保存されます。
- **保存キー名**:
  - `cb_knot_calc_size` : コマ寸法 (mm)
  - `cb_knot_calc_len` : コマ要尺 (mm)
  ※ このキーは `knot45-calc` および `size-call` と共通であり、同一サイト内でシームレスに同期されます。
- **値決定の優先順位**:
  1. **URLクエリパラメータ（API）**: `cb_knot_size`, `cb_knot_len` があれば最優先で適用し、localStorage も更新。
  2. **ブラウザ保存値（localStorage）**: 過去にユーザーが入力・計算した値があれば優先復元。
  3. **規定初期値**: 上記が何もない場合、**寸法 20.0 mm / 要尺 60.0 mm** を適用。

> [!IMPORTANT]
> **APIで指定しない場合の扱いとテスト時の注意点**
> URLパラメータで `cb_knot_size` や `cb_knot_len` を指定せずにツールを開いた場合、過去にツールを使用したことのあるブラウザ環境では、**規定初期値（20/60）ではなく、そのブラウザに保存されているユーザーの前回値が優先して読み込まれます**。
> そのため、デフォルト動作テスト（TC-01 等）で規定の初期値（20.0mm / 60.0mm）に基づいた計算結果を検証する際は、**シークレットウィンドウ（InPrivateブラウズ）を使用するか、ブラウザの開発者ツールで `localStorage.clear()` を実行してからアクセスしてください**。

### 1.3 受け付けるURLクエリパラメータ
| パラメータ名 | 型 | 説明 | 初期値 |
| :--- | :--- | :--- | :--- |
| `cb_model` | 文字列 | `knot` (推奨)。不一致時は処理をスキップ。 | - |
| `cb_knot_size`| 数値 (mm) | コマ寸法。片方指定時は要尺を自動補完。 | `20.0` (保存値優先) |
| `cb_knot_len` | 数値 (mm) | コマ要尺。片方指定時は寸法を自動補完。 | `60.0` (保存値優先) |
| `cb_w` | 数値 (mm) | 横幅ターゲット寸法。不足時は自動補完。 | - |
| `cb_d` | 数値 (mm) | 奥行ターゲット寸法。不足時は自動補完。 | - |
| `cb_h` | 数値 (mm) | 高さターゲット寸法。不足時は自動補完。 | - |
| `cb_mode` | 文字列 | 適合モード (`near`, `in`, `out`) | `near` |
| `cb_rim` | 整数 (コマ) | 折り返しのコマ数 (ひも長・本数に加算) | `0` (※初期バージョンは2) |
| `cb_add` | 数値 (コマ) | 縁の加算コマ数 (両端に加算 $\times 2$) | `3.0` |
| `cb_lap` | 数値 (コマ) | 側面の編みひも加算コマ数 | `3.0` |
| `cb_band` | 数値 (mm) | 参考バンド幅入力欄への反映値 | `寸法 / 2.236` |

## 🧪 2. テストケース & 検証結果報告

*※ 以下のテストは、localStorage がクリアされたクリーンな環境（初期値: 寸法20.0mm / 要尺60.0mm）を前提としています。*

| No | テストケース名 | URL付与用クエリ文字列 | 検証内容・期待される動作 | 結果 |
| :--- | :--- | :--- | :--- | :---: |
| **TC-01** | **デフォルト動作（初期状態）** | *(クエリなし)* | 横13, 縦4, 高9, 折0。サイズ: 26.0×8.0×18.0cm。編みひも本数=9本(9+0)。合計長=48.60m。 | 💚 SUCCESS |
| **TC-02** | **モデル指定＋コマ寸法・要尺** | `?cb_model=knot&cb_knot_size=25&cb_knot_len=75` | 寸法25mm, 要尺75mmが反映。サイズ 横32.5cm, 奥行10.0cm, 高22.5cm。 | 💚 SUCCESS |
| **TC-03** | **比率自動補完（Wのみ指定）** | `?cb_model=knot&cb_w=260` | W=260mmから自動計算: 横13コマ, 縦4コマ, 高9コマ。 | 💚 SUCCESS |
| **TC-04** | **比率自動補完（Hのみ指定）** | `?cb_model=knot&cb_h=200` | H=200mmから自動逆算: 高10コマ, 横14コマ, 縦5コマ。 | 💚 SUCCESS |
| **TC-05** | **比率自動補完（Dのみ指定）** | `?cb_model=knot&cb_d=100` | D=100mmから自動補完: 縦5コマ, 横15コマ, 高11コマ。 | 💚 SUCCESS |
| **TC-06** | **3辺指定＋内接モード(`in`)＋折り返し3コマ** | `?cb_model=knot&cb_w=295&cb_d=115&cb_h=195&cb_mode=in&cb_rim=3&cb_add=1.5&cb_lap=2` | 内接モードで端数切り捨て: 横14, 縦5, 高9, 折3。編みひも=12本(9+3)。縁加算1.5要尺、編み加算2要尺。 | 💚 SUCCESS |

| **TC-08** | **コマ要尺のみ指定（寸法自動補完）** | `?cb_model=knot&cb_knot_len=90` | 要尺90.0mm指定時、寸法が比率(2.236/6.43)により `31.3mm` に自動補完される。 | 💚 SUCCESS |
