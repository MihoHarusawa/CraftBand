# gauge-calc ツール仕様書 & テスト報告書

本ドキュメントは、四つ畳み編みの試し編みから高精度なコマ寸法・コマ要尺を算出する測定支援ツール `gauge-calc` の個別仕様、UI設計、統計ロジック、描画仕様、他ツール連携、およびブラウザ自動テスト結果をまとめたものです。
全体共通のAPI規格については、ルートディレクトリの [`api_specification.md`](../api_specification.md) を、WordPress実装のガイドラインについては [`wordpress_js_guidelines.md`](../wordpress_js_guidelines.md) を参照してください。

---

## 📖 1. ツール固有仕様 & 基本概念

### 1.1 役割と開発目的
四つ畳み編みでは、作り手の引き締め加減（手のキツさ・緩さ）や使用するクラフトバンドの素材厚によって、**1コマあたりの出来上がり寸法（コマ寸法）** と **1コマで消費するひも長（コマ要尺）** が大きく変動します。
`gauge-calc` は、事前に試し編みしたゲージ（3×3 または 2×2）の実測データ（残りひも長・コマ中心間寸法）を入力することで、以下の目的を達成します：
1. **正確なゲージ値の算出**: あなた固有のコマ要尺 (mm) とコマ寸法 (mm) を精密に算出。
2. **編み目の安定度評価**: 最大ブレ幅 (%)、変動係数 CV (%)、要尺/寸法比率から、引き締めの均一性や緩み・タイト度を客観判定。
3. **電卓ツールへのダイレクト連携**: 算出したゲージ値を引き継ぎ、[`knot-calc`](../knot-calc/knot-calc.md)（四つ畳み縦横）や [`knot45-calc`](../knot45-calc/knot45-calc.md)（四つ畳み斜め）を別タブで即座に起動。
4. **PDFレポート出力**: 測定値・統計サマリー・ガイド図を1枚のA4シートにまとめてダウンロード・印刷保存。

### 1.2 直感的なUI設計（案A：図と入力の一体化 & スマホ完全対応）

#### ① 2つの独立したCanvas図面
従来の「1つの図をタブで切り替える方式」を廃止し、測定対象に合わせて **2つの専用Canvas図面** を配置：
- **Canvas 1: ひも残り長（要尺測定）専用図**（セクション2）
- **Canvas 2: コマ寸法測定専用図**（セクション3）

#### ② 要尺図: 接する傾斜コマ ＋ 傾いたのこりひも ＋ 図を取り囲む直接入力
中央に実際の編み地と同様に **ぴったり接した9コマ（または4コマ）** を配置し、そこからコマと同じ傾き角度（$-26.5^\circ$）で外側に伸びるひもの外側に入力ボックスを配置：
- **上部**: 縦ひも $V_1 \sim V_k$ の上端残り長入力枠
- **下部**: 縦ひも $V_1 \sim V_k$ の下端残り長入力枠 ＋ 算出された要尺バッジ（例: `61.0 mm`）
- **左側**: 横ひも $H_1 \sim H_k$ の左端残り長入力枠
- **右側**: 横ひも $H_1 \sim H_k$ の右端残り長入力枠 ＋ 算出された要尺バッジ（例: `60.7 mm`）
- **未入力がひと目でわかる空白表示**:
  - ガイド用の初期プレースホルダー数字（85等）を廃止し、**未入力時は完全に空白**とすることで、入力済みかどうかが直感的に分かります。
- **スピンボタン非表示 & 3桁＋小数点の視認性確保**:
  - ブラウザ標準のスピンボタン（▲▼の矢印）を非表示化し、入力枠幅を拡大。10cm以上（例: `125.5`）の3桁＋小数点1位を入力しても数字が被らず、すっきりと中央に表示されます。
- **重なり・見切れの完全解消**:
  - $V_1, V_2, V_3$ の入力ボックスは、Canvas幅 220px に対してピッチ 68px、各幅 60px で配置され、ボックス間に十分な隙間を確保して重なりを解消。
  - 最小幅 360px のスマートフォンでも、左右の横ひも枠を含めた全体が横スクロールなしで収まります。

#### ③ 寸法図: 接する拡大コマ ＋ ラベルなし目一杯の数字入力 ＋ 方向別サブタブ
- コマ同士がぴったり接した編み地を画面中央に大きく拡大表示（コマサイズ $S = 66\text{px}$）。
- 各コマの中心（結び目の中心点）に白縁付き黒丸マークを表示。
- **「↔ 横方向の測定」と「↕ 縦方向の測定」のサブタブ切り替え**:
  - 横測定時は、隣り合う山の頂点間を結ぶオレンジ色の寸法線（両矢印）を表示。
  - 縦測定時は、縦ひもに沿って隣り合う山の頂点間を結ぶ紫色の寸法線（両矢印）を表示。
  - 矢印の中央に、**ラベル（横1_1等）を排した純粋な入力ボックス**を配置。ガイド数字なしの空白とし、枠目一杯に大きな太字数字が表示されます。
  - 測る区間が矢印でダイレクトに結ばれているため、ラベルがなくてもどこを測るかが明白です。

### 1.3 描画仕様（step4〜step8 幾何学準拠：バンド幅ずらし階段状接合 & のこりひも）
- **バンド幅分ずらした階段状接合（`step4.png` 〜 `step6.png` 幾何学）**:
  - 四つ畳み編みでは、あるコマから隣のコマへバンドが階段状（1コマ幅進み、バンド幅 $w = S/2$ 分シフト）に連なります。
  - これを回転角 $\theta = -\arctan(0.5) \approx -26.565^\circ$（クラフトバンド編みの約2:1傾斜）傾けることで、**行方向が完全水平、列方向が完全垂直**の直交グリッドに配置されます（`step5.png`, `step6.png`）。
  - 隣り合うコマの中心間距離は、水平・垂直ともに $D = \sqrt{5} w = \frac{\sqrt{5}}{2} S \approx 1.118 S$ となります。
  - コマ同士は接合部（長さ $w$）でぴったり接触し、4コマに囲まれた中央部には同じ傾きの **$w \times w$ の正方形の穴（隙間）** が美しく形成されます。
- **のこりひも（腕）の四方延伸（`step8.png` 準拠）**:
  - **縦ひも上端（ピンク）**: 行0の各コマの左上象限（縦ひも）から上方へまっすぐ伸びる。
  - **縦ひも下端（ピンク）**: 行 $k-1$ の各コマの右下象限（縦ひも）から下方へまっすぐ伸びる。
  - **横ひも左端（水色）**: 列0の各コマの左下象限（横ひも）から左方へまっすぐ伸びる。
  - **横ひも右端（水色）**: 列 $k-1$ の各コマの右上象限（横ひも）から右方へまっすぐ伸びる。
  - 各ひもの脇に測定方向を示すガイド矢印（縦ひも: 赤、横ひも: 青）を配置。
- **コマ中心（山・頂点）マークと寸法線（`input-size.png` 準拠）**:
  - 各コマの中心に実物通りの黒丸（山頂点）を描画。
  - 横測定時は、水平に並ぶ黒丸同士を結ぶ **オレンジ色の水平寸法線（両矢印）** を表示し、その中央に入力枠を配置。
  - 縦測定時は、垂直に並ぶ黒丸同士を結ぶ **紫色の垂直寸法線（両矢印）** を表示し、その中央に入力枠を配置。
  - 測定線と入力枠が一直線上に重なり、どこを測って入力するかが直感的に明白。
- **クラフトバンドの長手方向に沿った4本ストライプライン（筋）**:
  - 各バンド（水色・ピンク）に4本の筋（3本の分割線）を描画。
  - バンドの折れ曲がりと重なり順（右綾・左綾の立体構造）が極めてリアルに視認可能。
- **右綾（標準）と左綾の切り替え**:
  - `scale(-1, 1)` による幾何学的反転描画により、右綾と左綾の編み目の向き・ひもの出入りが完全に連動。

### 1.4 設計ポリシー & ガイドライン遵守

#### ① 入力単位の統一 & 入力枠の拡大（「mm」表記の省略）
- cm と mm の混在による入力ミスを防止するため、**「使用したひも長」のみ cm** とし、**測定値（ひもの残り長さ・コマ寸法）はすべて【 mm 】単位に完全統一**しました。
- 各入力ボックス横の「mm」表記を削り、その分 `<input>` 要素の幅・フォントサイズを拡大。スマートフォンでもタップしやすく誤入力を防ぐUIを実現しました。
- ツールの冒頭および測定セクションに、目立つ警告バナー（`⚠️ すべて mm 単位で入力してください`）を配置。

#### ② `localStorage` 保存の意図的非使用
- 本ツールで入力・算出する値は「測定・試行錯誤の途中段階」であるため、**本ツール自身ではブラウザ（`localStorage`）への永続化保存を行いません**。
- 電卓ツール（`knot-calc`, `knot45-calc`）を開いた際に、電卓側で値が確定（fix）され保存されます。

#### ③ 外部画像ファイルへの完全非依存 & 図面表示領域の最大活用
- すべて HTML5 Canvas API により自律描画されます。
- 本図面は印刷出力を行わないため、Canvasフッターの日時・URL描画を削除し、キャンバス領域全体を図の描画と測定線の視認性向上にフル活用しています。

#### ④ WordPress Gutenberg 保存破壊対策（危険演算子のゼロ化）
- スニペット版（`gauge-calc-snippet.html`）では、JavaScriptコード内から `&&`, `||`, `<`, `>`, `<=`, `>=` を完全に排除しています（`wordpress_js_guidelines.md` 第14項に完全準拠）。

### 1.5 幾何パラメータの定数化・描画コードのシンプル化
本ツールで描画する四つ畳み編みパターンは、ゲージサイズ（3×3 または 2×2）および編み方向（右綾・左綾）の決まった静的幾何構造です。そのため、描画時の無駄な三角関数計算や重複座標計算を全廃し、**定数テーブルによる静的設定**にシンプル化しています：
- **傾斜角定数**: `THETA_TILT = -0.463648`（約 -26.565度, -arctan(0.5)）
- **矢頭角定数**: `ARROW_ANGLE = 0.523599`（30度, pi/6）
- **スタイル定数**: バンド色（縦ピンク `#fbcfe8`、横水色 `#bae6fd`）、外枠色、4本筋色、矢印色を `DRAW_THEME` に集約。
- **パターン設定テーブル**:
  - `CFG_LEN`: Canvas 1（要尺図 220×220）用 (k=3: S=28, D=31.3 / k=2: S=40, D=44.7)
  - `CFG_SIZE`: Canvas 2（寸法図 360×350）用 (k=3: S=68, D=76.0 / k=2: S=94, D=105.1)
- **描画関数の責務分離**:
  - `drawBandBlock`: 1本のバンドブロック（外枠・4本筋・＝形省略）
  - `drawSteppedKnot`: 1コマ（4象限の接合・太外枠・中心山マーク）
  - `drawDoubleArrow`: 両端矢印（太線・大型矢頭）
  - `drawCenterMark`: 矢印が指す結び目の中心点マーク（白フチ二重円）
これにより、毎描画時の計算コストを最小限に抑え、今後の「値をもとにした判定」や「出力機能」の改修時にも描画に影響を与えず安全に開発を進められる保守性を確保しました。

## 📐 2. 入力項目と測定方法

### 2.1 基本仕様セクション
| 項目 | 選択肢 / 入力範囲 | デフォルト値 | 単位 | 説明 |
| :--- | :--- | :--- | :---: | :--- |
| **ゲージサイズ** | `3×3 (9コマゲージ・推奨)` / `2×2 (4コマゲージ)` | `3×3` | - | 試し編みした四つ畳みのコマ数。3×3の方が統計母数が多く高精度。 |
| **編み目の向き (綾)** | `右側 (右綾・標準)` / `左側 (左綾)` | `右側 (右綾)` | - | 編み目の交差方向。Canvasガイド図の向きが反転します。 |
| **使用したひも長** | 実数 (step: 0.1) | `35.0` | **cm** | 試し編みに使用したひものカット長（全ひも同寸）。これのみ cm 単位。 |

### 2.2 ひもの残り長さ測定（コマ要尺算出）
- 3×3 の場合は 6本（縦ひも V1〜V3、横ひも H1〜H3）、2×2 の場合は 4本（V1〜V2、H1〜H2）。
- 各ひもについて、それぞれの端の残りひも長（コマの端から先端まで）を **mm 単位** で実測入力します（例: 8.5cm の場合は `85.0` と入力）。
- **1本あたりのコマ要尺 (mm)**:
  $$\text{全ひも長(mm)} = \text{ひも長(cm)} \times 10$$
  $$\text{コマ要尺(mm)} = \frac{\text{全ひも長(mm)} - \text{端1残り(mm)} - \text{端2残り(mm)}}{\text{コマ数 } k}$$
- 入力値が $0$ 以下、または残り長合計が全ひも長を超える場合は、赤枠（エラー表示）となり計算から除外されます。

### 2.3 コマ寸法の測定
- 隣り合うコマの「中心から中心まで（結び目の中心間）」の距離をノギスまたは定規で測定し、**mm 単位** で入力します。
- 3×3 の場合: 横方向 6点（3行 × 2区間）＋ 縦方向 6点（3列 × 2区間）＝ **計12点**
- 2×2 の場合: 横方向 2点（2行 × 1区間）＋ 縦方向 2点（2列 × 1区間）＝ **計4点**

## 📊 3. 統計計算ロジック & 判定基準

$$\text{平均値 (Mean)} = \bar{x} = \frac{1}{N} \sum_{i=1}^{N} x_i$$
$$\text{不偏分散} = s^2 = \frac{1}{N-1} \sum_{i=1}^{N} (x_i - \bar{x})^2 \quad (N \ge 2)$$
$$\text{標準偏差} = s = \sqrt{s^2} \quad (N \ge 2)$$
$$\text{最大ブレ幅 (\%)} = \frac{\max(X) - \min(X)}{\bar{x}} \times 100$$
$$\text{変動係数 (CV \%)} = \frac{s}{\bar{x}} \times 100 \quad (N \ge 2)$$
$$\text{要尺 / 寸法 比率} = \frac{\bar{x}_{\text{len}}}{\bar{x}_{\text{size}}} \quad (\text{理論値 約2.88倍: } 6.43 / 2.236)$$

### 3.3 要尺 / 寸法 比率の判定基準（暫定10段階）
四つ畳み編みでは、ひも消費量（コマ要尺）と出来上がり寸法（コマ寸法）の比率が、編み地の「厚み・手の硬さ」を表す重要な指標となります。比率は以下の10段階で客観評価されます：

| 比率範囲 | 判定テキスト | 補足・状態 |
| :--- | :--- | :--- |
| **2.90 未満** | **幅に対して非常に薄い** | ※ 理論値（約2.876倍）未満は異常値として警告（要確認） |
| **2.90 以上 〜 2.95 未満** | **幅に対してかなり薄い** | 引き締めが強め、または薄手バンド |
| **2.95 以上 〜 3.00 未満** | **幅に対して薄い** | 軽快・タイトめな仕上がり |
| **3.00 以上 〜 3.05 未満** | **幅に対して少し薄い** | すっきりした標準仕上がり |
| **3.05 以上 〜 3.10 未満** | **幅に対して薄め** | バランスの取れた標準域 |
| **3.10 以上 〜 3.15 未満** | **幅に対して少し厚みがある** | ふんわりし始めた標準域 |
| **3.15 以上 〜 3.20 未満** | **幅に対して厚みがある** | しっかりとした厚み |
| **3.20 以上 〜 3.30 未満** | **幅に対してかなり厚みがある** | ふっくら・ボリューミーな編み地 |
| **3.30 以上 〜 3.40 未満** | **幅に対してとても厚い** | 非常に緩やか、または厚手バンド |
| **3.40 以上** | **幅に対して非常に厚い** | ※ 4.0以上は異常値として警告（要確認） |

※ 今後、測定データの蓄積・経験の増加に伴い、閾値や表現の調整が柔軟に行える設計となっています。

### 段階的表示ガード
| 有効データ数 $N$ | 平均値表示 | 最大ブレ幅表示 | 変動係数 (CV%) 表示 |
| :--- | :--- | :--- | :--- |
| **$N = 0$** | `-- mm` | `--` | `--` |
| **$N = 1$** | 入力値をそのまま表示 (`.toFixed(1)`) | `※ 2点以上で表示` | `※ 4点以上で表示` |
| **$N = 2 \sim 3$** | 平均値表示 (`.toFixed(2)`) | **最大ブレ幅 (%) と評価テキスト** | `※ 4点以上で表示` |
| **$N \ge 4$** | 平均値表示 (`.toFixed(2)`) | **最大ブレ幅 (%) と評価テキスト** | **CV (%) と編み目安定度判定** |

### 3.2 体系化された入力警告判定システム
測定値に対する警告は、複数の条件が同時に発生した場合でもユーザーの混乱を防ぐため、**優先順位の高い1点のみ** を表示します。警告発生時には、原因に応じた警告メッセージとともに、固定の **【確認チェックリスト】** を一体で提示します。

#### ① 警告チェックの優先順位と判定ルール
| 優先順位 | 判定条件 | 警告メッセージ | 判定の補足 |
| :---: | :--- | :--- | :--- |
| **1** | **負数がある** | **マイナスの入力があります** | ひも長、残りひも長、コマ寸法の入力値に負数がある場合、および「ひも長 － 残りひも長 の差分がマイナス」の場合を含む |
| **2** | **ゼロがある** | **ゼロの入力があります** | ひも長、残りひも長、コマ寸法の入力値に0がある場合、および「ひも長 － 残りひも長 の差分が0」の場合を含む |
| **3** | **最大ブレ幅が極端に大** | **入力値が大きく異なっています** | 最大ブレ幅 $\ge 15.0\%$ の場合 |
| **4** | **要尺／寸法 比率が異常** | **寸法・要尺としては異常な値です** | 比率算出条件（要尺・寸法が各1点以上）を満たした上で、比率が理論値（$6.43 / 2.236 pprox 2.8757$）未満、または $4.0$ 以上の場合 |

※ ゼロや負数などの除外は従来通り行われ、有効な正の測定値のみが統計計算に算入されます。

#### ② 提示する確認チェックリスト（固定）
警告発生時、メッセージの直下に以下のチェックリストが表示されます：
- 入力単位や桁に間違いはありませんか。mm単位の数値になっていますか
- ひも長は正しくセットされていますか。ひも長のみcm 単位です。
- コマ要尺の端の対応は正しいですか。上端・下端、左端・右端がペアです

## 💾 4. 測定結果の保存・シェア仕様

測定結果をローカル保存（PDF）およびコミュニティ共有（Google フォーム & スプレッドシート）するための専用セクションです。

### 4.1 任意入力項目（作品・素材情報）
測定データの背景となる素材情報を任意で記録できます（未入力のままでも保存・シェア可能ですが、記載いただくとPDFの記録や、みんなの参考データとして役立ちます）：
- **メーカー・製品名 (ショップ名やシリーズ名など、わかる範囲で)**: `shareBrand`

- **バンド幅 [mm]**: `shareBandWidth`
- **使用した本幅数 (割かずに使った場合は全幅数と同じ)**: `shareUsedStrap`
- **編み心地・ひとことメモ**: `shareMemo`
