# クラフトバンド Webツール群 外部連携 API 共通仕様書 (API Specification)

本ドキュメントは、WordPress上で動作するクラフトバンド関連Webツール群において、**「外部システム・AIエージェント・統合ランチャーからURLパラメータを通じてツールを制御し、計算・シミュレーション結果をプログラムで抽出するための共通インターフェース規格」** を定義したものです。

---

## 1. 基本設計方針

### 1.1 WordPress予約変数との衝突回避（Reserved Query Variables 対策）
WordPressコアは、日付やアーカイブ検索等のために内部で予約クエリ変数（`w` = Week, `d` = Day, `h` = Hour, `s` = Search 等）を保持しています。これらと同一のパラメータ名を使用すると、WordPressがリクエストを乗っ取り「404 Not Found」エラーが発生します。
そのため、本システムで外部公開・連携するすべてのURLクエリパラメータには、**必ず `cb_` プレフィックス（CraftBand）を強制付与**します。

### 1.2 単位非依存性（Unit-Agnostic）の設計原則
クラフトバンドの計算アルゴリズムは、目標サイズとバンド幅・コマ寸法の**相対的な比率関係**に基づいてコマ数やひも本数を算出します。
そのため、基本ロジック自体はミリメートル（mm）、センチメートル（cm）、インチ（inch）などの実単位に依存せず動作します。
※ ただし、WebツールのUIおよび Single-Shot JSON 出力においては、日本国内の標準慣行に合わせて **「目標寸法・バンド幅・コマ寸法はミリメートル (mm)」**、**「画面上の仕上がりサイズ表示はセンチメートル (cm)」** に統一しています。

### 1.3 セキュリティ・耐久設計（不正値の安全フォールバック）
- パラメータに文字列や NaN、負数などの不正な値が渡された場合、スクリプトがクラッシュして画面が真っ白になることを防ぐため、バリデーションと安全フォールバック（規定初期値への差し戻し、最小コマ数1への制限など）を各ツールに実装しています。
- モデル識別子（`cb_model`）が自身のツール種別と一致しない場合は、パラメータの適用およびJSON書き出しを安全にスキップします。

## 2. 共通インターフェース仕様

### 2.1 共通URLクエリパラメータ体系

| パラメータ名 | 型 | 説明 | 指定時の動作とフォールバック |
| :--- | :--- | :--- | :--- |
| `cb_model` | 文字列 | 対象モデル識別子 | `square`, `square45`, `knot`, `knot45`。不一致時はパラメータ処理をスキップ。 |
| `cb_mode` | 文字列 | 適合計算モード | `near` (最寄り・デフォルト), `in` (内接/指定寸法以下), `out` (外接/指定寸法以上) |
| `cb_w` | 数値 (mm) | 横幅ターゲット寸法 | 目標とする横幅。コマ数・本数の算出に利用。 |
| `cb_d` | 数値 (mm) | 奥行ターゲット寸法 | 目標とする奥行。コマ数・本数の算出に利用。 |
| `cb_h` | 数値 (mm) | 高さターゲット寸法 | 目標とする高さ。コマ数・段数の算出に利用。 |
| `cb_add` | 数値 (コマ/要尺) | 縁の折り返し加算 | 縁を始末するための余白長さ（片側または両端）。 |
| `cb_rim` | 整数 | 縁重ね本数 / 折返コマ数 | 四角かごでは「縁に重ねる本数」、四つ畳みでは「折り返しのコマ数」。 |
| `cb_lap` | 数値 (コマ/要尺) | 側面の編みひも加算 | 側面をぐるぐる巻き上げる編みひもの重なり代（縦横立ち上げモデルのみ）。 |

### 2.2 3次元ターゲット寸法のアスペクト比自動補完ロジック

外部システムやAIからターゲット寸法を渡す際、3次元寸法（幅 $W$、奥行 $D$、高さ $H$）の一部のみが指定されている場合、手芸バッグとしての標準的で美しいプロポーションに基づいて未指定の寸法を自動補完します。

#### 補完基準比率
1. **幅と高さ ($W : H$) = $\sqrt{2} : 1$** （約 $1.414 : 1$ / A4用紙規格比率に準拠）
2. **幅と奥行 ($W : D$) = $3 : 1$** （標準的なトートバッグ・収納バスケットの底面比率）

#### 補完計算の数式
- **$W$ のみ指定された場合**:
  $$D = \frac{W}{3}, \quad H = \frac{W}{\sqrt{2}}$$
- **$H$ のみ指定された場合**:
  $$W = H \times \sqrt{2}, \quad D = \frac{W}{3} = \frac{H \times \sqrt{2}}{3}$$
- **$D$ のみ指定された場合**:
  $$W = D \times 3, \quad H = \frac{W}{\sqrt{2}} = \frac{D \times 3}{\sqrt{2}}$$
- **2箇所が指定された場合**:
  指定された2つの寸法をそのまま使用し、未指定の1箇所のみを上記比率に基づいて算出します。
  - $W, D$ 指定 $\to$ $H = W / \sqrt{2}$
  - $W, H$ 指定 $\to$ $D = W / 3$
  - $D, H$ 指定 $\to$ $W = D \times 3$

### 2.3 Single-Shot JSON DOM書き出し仕様

外部のプログラム（Playwright、Puppeteer、Pythonスクリプト等）やAIエージェントが、計算結果やシミュレーション結果を瞬時に抽出できるよう、初回ロード時の計算完了タイミングで一度だけ `<body>` の末尾に不可視の `<script id="craftband-simulation-data">` タグを出力します。

#### 取得用 JavaScript コード
```javascript
const result = JSON.parse(document.getElementById('craftband-simulation-data').textContent);
console.log(result);
```

#### 共通JSONデータ構造
```json
{
  "model": "square",
  "koma": {
    "w": 17,
    "d": 5,
    "h": 12,
    "fold": 2
  },
  "size": {
    "w": 263.5,
    "d": 77.5,
    "h": 186.0
  },
  "total_length": 14860.0,
  "cut_list": [
    { "len": 605.0, "num": 5, "name": "横ひも" },
    { "len": 791.0, "num": 17, "name": "縦ひも" },
    { "len": 751.0, "num": 14, "name": "編みひも" }
  ]
}
```
- **`model`**: モデル識別文字列。
- **`koma`**: 適合された各軸のコマ数（または本数・段数）。
- **`size`**: 出来上がりの外寸（単位: mm）。
- **`total_length`**: 必要となる全バンド・ひもの合計消費長（単位: mm）。
- **`cut_list`**: ひもの切り出しリスト（`len`: 1本あたりの長さ mm、`num`: 必要本数、`name`: ひもの役割名称）。

## 3. 第1部：サイズ計算系ツール仕様 (Size Calculation Family)

### 3.1 ツール一覧と特性比較マトリクス

| ツール識別子 | ツール名称 | 編み方・立ち上げ構造 | 1コマの基準単位 | 適合単位の制限 | 主なパラメータ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `square` | [square-calc](./square-calc/square-calc.md) | 四角かご（縦横立ち上げ） | バンド幅＋すき間 ($1.0\times$) | 底面は**奇数本**制限 | `cb_band`, `cb_gap`, `cb_rim`, `cb_lap` |
| `square45` | [square45-calc](./square45-calc/square45-calc.md) | 北欧編み（斜め45度立ち上げ） | 対角線長 ($\sqrt{2}\times$) | 底面整数、高さ**0.5刻み** | `cb_band`, `cb_gap`, `cb_add` |
| `knot` | [knot-calc](./knot-calc/knot-calc.md) | 四つ畳み編み（縦横立ち上げ） | コマ寸法 ($1.0\times$) / コマ要尺 | 整数コマ | `cb_knot_size`, `cb_knot_len`, `cb_rim`, `cb_lap` |
| `knot45` | [knot45-calc](./knot45-calc/knot45-calc.md) | 四つ畳み編み（斜め45度立ち上げ） | 対角線長 ($\sqrt{2}\times$) / コマ要尺 | 底面整数、高さ**0.5刻み** | `cb_knot_size`, `cb_knot_len`, `cb_same_len`, `cb_rim` |

### 3.2 パラメータ対応マトリクス表

| パラメータ名 | square-calc | square45-calc | knot-calc | knot45-calc | size-call (ランチャー) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| `cb_model` | `square` | `square45` | `knot` | `knot45` | 4種すべて受領・中継 |
| `cb_mode` | ○ | ○ | ○ | ○ | ○ (中継) |

| `cb_knot_size` | × | × | ○ | ○ | ○ (knot系へ中継) |
| `cb_knot_len` | × | × | ○ | ○ | ○ (knot系へ中継) |
| `cb_add` | ○ (折り返しコマ) | ○ (折り返しコマ) | ○ (縁の加算要尺) | ○ (縁の加算要尺) | ○ (中継) |
| `cb_rim` | ○ (縁重ね本数) | × | ○ (折返コマ数) | ○ (折返コマ数) | ○ (中継) |
| `cb_lap` | ○ (側面編み加算) | × | ○ (側面編み加算) | × | ○ (縦横のみ中継) |
| `cb_same_len` | × | × | × | ○ (ひも長モード) | × (knot45規定値利用) |

> [!IMPORTANT]
> **四つ畳み系（knot系）とバンド幅の関係**
> 四つ畳み編みは、バンドのすき間が存在せず、コマの結び方（ゲージ）によって寸法と要尺が決まります。
> そのため、`knot-calc` および `knot45-calc` では **`cb_band` や `cb_gap` を直接の計算パラメータとして使用せず、`cb_knot_size`（コマ寸法）と `cb_knot_len`（コマ要尺）を引数として渡す設計** としています。
> ランチャー（`size-call`）から knot 系を起動する際も、`cb_band` と `cb_gap` は URL 引数から除外されます。

### 3.3 各ツールの固有API仕様

#### 1. square-calc (四角かご・縦横立ち上げ)
- **URL**: `https://labo.com/CraftBand/sharing/square-calc/`
- **底面本数の奇数制限**:
  クラフトバンドの四角かご（縦横編み）では、編みひもが交互に規則正しく回るよう、底面の縦ひも本数・横ひも本数が**必ず奇数**である必要があります。
  APIでターゲット寸法を与えられた際、最も寸法が近くなる奇数本数（`mode=in` では切り下げ奇数、`mode=out` では切り上げ奇数）に自動適合します。

#### 2. square45-calc (北欧編み・斜め立ち上げ)
- **URL**: `https://labo.com/CraftBand/sharing/square45-calc/`
- **対角線進みと0.5刻み制限**:
  ひもが底面および側面を45度の角度で通過するため、1コマ進むごとの実寸法は $\text{diagMm} = (\text{band} + \text{gap}) \times \sqrt{2}$ となります。
  また、側面の立ち上げ形状の幾何学的制約により、底面コマ数は整数刻み、**高さコマ数は 0.5 刻み（1.0, 1.5, 2.0...）** に適合されます。

#### 3. knot-calc (四つ畳み編み・縦横立ち上げ)
- **URL**: `https://labo.com/CraftBand/sharing/knot-calc/`
- **コマ寸法・要尺の自動補完**:
  `cb_knot_size` のみ渡された場合、標準比率（$6.43 / 2.236 \approx 2.87567$）により要尺を自動算出します。逆に `cb_knot_len` のみ渡された場合は寸法を自動逆算します。
- **ブラウザ永続化（localStorage）**:
  ユーザー固有のゲージ値を `cb_knot_calc_size` および `cb_knot_calc_len` として保存します。API引数が渡されない場合は、このブラウザ保存値が優先して復元されます（初期値は 20.0mm / 60.0mm）。

#### 4. knot45-calc (四つ畳み編み・斜め立ち上げ)
- **URL**: `https://labo.com/CraftBand/sharing/knot45-calc/`
- **3方向 $\sqrt{2}$ 倍の幾何学特性**:
  斜め四つ畳み編みでは、幅・奥行・高さの3軸すべてがコマの対角線方向を向くため、仕上がりサイズは3方向ともに $\text{コマ寸法} \times \sqrt{2}$ で計算されます。
- **ひも長モード (`cb_same_len`)**:
  - `0`: 最適長（各位置で切り分ける無駄のないカット長）
  - `1`: 四方同一長（長方形底のとき $diff - 1$ を加味した同寸カット）
  - `2`: 対角線同一長（底編み正方形の対角線に揃えた同寸カット）
- **ブラウザ永続化（localStorage）**:
  `knot-calc` と同じキー（`cb_knot_calc_size`, `cb_knot_calc_len`）を使用し、サイト全体で共通のゲージ設定が共有されます。

#### 5. size-call (かごサイズ概算ランチャー)
- **URL**: `https://labo.com/CraftBand/sharing/size-call/`
- **役割**:
  ユーザーが目標サイズ、バンド幅、または四つ畳みゲージを入力し、ワンクリックで最適な電卓（4種）へ引数を引き継いで別タブ起動するランチャーツールです。
  API引数を受け取って初期状態をセットアップすることも可能です。
