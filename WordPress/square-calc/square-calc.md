# square-calc ツール仕様書 & テスト報告書

本ドキュメントは、WordPress上で動作する `square-calc`（縦横編みプラかご・四角かごサイズ計算ツール）の個別仕様、計算ロジック、およびテスト検証結果をまとめたものです。
全体共通のAPI規格については、ルートディレクトリの [`api_specification.md`](../api_specification.md) を参照してください。

---

## 📖 1. ツール固有仕様

### 1.1 基本構造と立ち上げ方式
- **編み方**: 四角かご（縦横立ち上げ）。
- **底面構造**: 縦ひもと横ひもが直交して底面長方形を形成。
- **側面構造**: 底面から直角に立ち上がったひもに対して、編みひもを水平に巻き上げていく構造。
- **1コマの進み**: バンド幅＋すき間（mm）。

### 1.2 底面本数の奇数制限ロジック
クラフトバンドの縦横編みでは、編みひもが交互に規則正しく回るよう、底面の縦ひも本数・横ひも本数が**必ず奇数**でなければなりません。
APIでターゲット寸法を与えられた際、以下のルールで適合本数を決定します：
- `mode=near` (デフォルト): 最も目標寸法に近い奇数本数。
- `mode=in` (内接): 目標寸法を超えない最大の奇数本数。
- `mode=out` (外接): 目標寸法以上の最小の奇数本数。

### 1.3 受け付けるURLクエリパラメータ
| パラメータ名 | 型 | 説明 | 初期値 |
| :--- | :--- | :--- | :--- |
| `cb_model` | 文字列 | `square` (必須)。不一致時は処理をスキップ。 | - |
| `cb_w` | 数値 (mm) | 横幅ターゲット寸法。不足時は自動補完。 | - |
| `cb_d` | 数値 (mm) | 奥行ターゲット寸法。不足時は自動補完。 | - |
| `cb_h` | 数値 (mm) | 高さターゲット寸法。不足時は自動補完。 | - |
| `cb_mode` | 文字列 | 適合モード (`near`, `in`, `out`) | `near` |
| `cb_band` | 数値 (mm) | バンド基本幅 | `15.0` |
| `cb_gap` | 数値 (mm) | バンド間のすき間 | `0.5` |
| `cb_add` | 数値 (コマ) | 縁の折り返し加算コマ数 | `5.0` |
| `cb_rim` | 整数 (本) | 縁に重ねる本数 | `2` |
| `cb_lap` | 数値 (コマ) | 側面の編みひも加算コマ数 | `7.0` |

## 🧪 2. テストケース & 検証結果報告

### 2.1 パラメータ指定が無い場合の初期値（デフォルト挙動）
- **検証URL**: `https://labo.com/CraftBand/sharing/square-calc/`
- **期待される動作**:
  - URLパラメータが無い場合は、初期サイズとして「B5横プリセット (幅 257mm, 高さ 182mm)」が適用され、奇数本数制限に従って自動計算されます。
  - 合計バンド幅 $15.5\text{ mm}$ (バンド15mm + すき間0.5mm) を基準とした適合計算：
    - $W = \text{toOdd}(257 / 15.5) = \mathbf{17}\text{ 本}$
    - $D = \text{toOdd}((257 / 3) / 15.5) = \text{toOdd}(5.52) = \mathbf{5}\text{ 本}$
    - $H = \text{round}(182 / 15.5) = \mathbf{12}\text{ 段}$
- **検証結果**: 💚 **SUCCESS** (画面上の表示が W=17本, D=5本, H=12段 で綺麗にロード完了)

---

### 2.2 比率補完テスト：Wのみ指定
- **検証URL**: `?cb_model=square&cb_w=250`
- **計算プロセス**:
  - $W = 250\text{ mm}$
  - $D = 250 / 3 = 83.33\text{ mm}$ に自動補完。
  - $H = 250 / \sqrt{2} = 176.78\text{ mm}$ に自動補完。
  - 合計幅 $15.5\text{ mm}$・`mode=near` (最寄り適合) で適合計算：
    - **横本数**: $250 / 15.5 = 16.13$ ➡ 最寄りの奇数 = **`17` 本**
    - **縦本数**: $83.33 / 15.5 = 5.38$ ➡ 最寄りの奇数 = **`5` 本**
    - **高さ段数**: $176.78 / 15.5 = 11.41$ ➡ 最寄りの整数 = **`11` 段**
- **検証結果**: 💚 **SUCCESS** (W=17本, D=5本, H=11段 がフォームに自動同期ロード)

---

### 2.3 比率補完テスト：Hのみ指定
- **検証URL**: `?cb_model=square&cb_h=200`
- **計算プロセス**:
  - $H = 200\text{ mm}$
  - $W = 200 \times \sqrt{2} = 282.84\text{ mm}$ に自動逆算補完。
  - $D = 282.84 / 3 = 94.28\text{ mm}$ に自動補完。
  - 合計幅 $15.5\text{ mm}$・`mode=near` で適合計算：
    - **横本数**: $282.84 / 15.5 = 18.25$ ➡ 最寄りの奇数 = **`19` 本**
    - **縦本数**: $94.28 / 15.5 = 6.08$ ➡ 最寄りの奇数 = **`7` 本**
    - **高さ段数**: $200 / 15.5 = 12.90$ ➡ 最寄りの整数 = **`13` 段**
- **検証結果**: 💚 **SUCCESS** (W=19本, D=7本, H=13段 が自動入力され描画完了)

---

### 2.4 フルパラメータ指定 ＋ 外接適合（mode=out）
- **検証URL**: `?cb_model=square&cb_w=250&cb_d=100&cb_h=200&cb_mode=out&cb_band=15&cb_gap=0&cb_add=3&cb_rim=2&cb_lap=3.5`
- **計算プロセス**:
  - バンド合計幅 = $15.0\text{ mm}$
  - 加算余裕値: 折り返し = `3` コマ, 側面編み加算 = `3.5` コマ, 縁重ね = `2` 本
  - `mode=out` (目標サイズ以上の最小奇数/整数) で適合計算：
    - **横本数**: $250 / 15.0 = 16.67$ ➡ $16.67$ 以上の最小奇数 = **`17` 本** ($17 \times 15.0 = 255\text{mm} \ge 250$)
    - **縦本数**: $100 / 15.0 = 6.67$ ➡ $6.67$ 以上の最小奇数 = **`7` 本** ($7 \times 15.0 = 105\text{mm} \ge 100$)
    - **高さ段数**: $200 / 15.0 = 13.33$ ➡ $13.33$ 以上の最小整数 = **`14` 段** ($14 \times 15.0 = 210\text{mm} \ge 200$)
- **検証結果**: 💚 **SUCCESS**
  - バンド幅: `15`, すき間: `0`, 横 `17`本, 縦 `7`本, 高さ `14`段, 折り返し `3`コマ, 加算 `3.5`コマ, 縁 `2`本 が完全にフォームにセットされ、Single-Shot JSON が出力されました。

### 2.5 異常値・境界条件（耐久性テスト）
- **検証URL**: `?cb_model=square&cb_w=-100&cb_band=invalid_data`

  - `cb_w` の負の値 `-100` も、安全ガードによりクラッシュせず最小コマ数にフォールバックします。
- **検証結果**: 💚 **SUCCESS** (スクリプトクラッシュを一切起こさず正常動作)
