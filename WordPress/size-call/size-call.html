[AI / Developer API Reference]

This page supports initialization via URL query parameters and acts as a launcher for orthogonal, diagonal Nordic, and knot weaving craft band calculators.

💡 Unit-Agnostic Note: The core calculation logic is entirely unit-agnostic (works with millimeters, centimeters, inches, etc.) as long as the relative ratios between the band, gap, knot dimensions, and target size parameters remain consistent.
Supported Query Parameters:
  • cb_model : square (Orthogonal) | square45 (Diagonal Nordic) | knot (Knot Orthogonal) | knot45 (Knot Diagonal)
  • cb_mode : out (Envelope target item / Min size) | in (Fit inside shelf / Max size)
  • cb_w, cb_d, cb_h : Target width, depth, height. Unit-agnostic (e.g. mm, cm, inches). (Note: In this specific size-call launcher UI, cm is internally scaled 10x to match calculator ratios)
  • cb_band : Band width (for square / square45).
  • cb_gap : Band gap (for square / square45).
  • cb_knot_size : Knot piece dimension in mm (for knot / knot45).
  • cb_knot_len : Knot piece required length in mm (for knot / knot45).
  • cb_add : Fold-back margin (one side) in koma / length units
  • cb_rim : Rim overlap count (Orthogonal square) | Fold-back knot count (knot / knot45)
  • cb_lap : Side weaving band overlap margin in koma / length units (Orthogonal square / knot)
Launch Destinations:
  • Square Orthogonal: https://labo.com/CraftBand/sharing/square-calc/
  • Square Diagonal (Nordic): https://labo.com/CraftBand/sharing/square45-calc/
  • Knot Orthogonal: https://labo.com/CraftBand/sharing/knot-calc/
  • Knot Diagonal: https://labo.com/CraftBand/sharing/knot45-calc/
Receiving Calculation Results (JSON Output):

The target calculators embed their complete calculation and simulation results inside the rendered HTML as a structured JSON block.

To extract the calculated data programmatically or via AI agents, parse the content of the following DOM element:

const result = JSON.parse(document.getElementById('craftband-simulation-data').textContent);
