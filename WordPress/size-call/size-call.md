# size-call ツール仕様書 & テスト報告書

本ドキュメントは、WordPress上で動作する `size-call`（かごサイズ概算ランチャー）の個別仕様、操作連動ロジック、外部電卓へのパラメータ転送仕様、およびテスト検証結果をまとめたものです。
全体共通のAPI規格については、ルートディレクトリの [`api_specification.md`](../api_specification.md) を参照してください。

---

## 📖 1. ツール固有仕様

### 1.1 役割と基本概念
`size-call` は、ユーザーが希望する目標サイズ（横幅・奥行・高さ）、バンド仕様、または四つ畳み編みのゲージ値を入力することで、以下の4つの専用計算ツールへパラメータを引き継いで別タブで開くランチャー（統合起点）ツールです：
1. **縦横に立ち上げる（四角かご）** $\to$ [`square-calc`](../square-calc/square-calc.md)
2. **斜めに立ち上げる（北欧編み）** $\to$ [`square45-calc`](../square45-calc/square45-calc.md)
3. **四つ畳みで縦横に立ち上げる** $\to$ [`knot-calc`](../knot-calc/knot-calc.md)
4. **四つ畳みで斜めに立ち上げる** $\to$ [`knot45-calc`](../knot45-calc/knot45-calc.md)

---

### 1.2 モデル選択とセクション動的表示制御

選択されたモデルに応じて、表示項目やラベル、単位表記が動的に切り替わります。

| セクション / 項目 | square (四角) | square45 (北欧) | knot (四つ畳み縦横) | knot45 (四つ畳み斜め) |
| :--- | :---: | :---: | :---: | :---: |
| **四つ畳み編みの設定** | 非表示 | 非表示 | **表示** (寸法・要尺) | **表示** (寸法・要尺) |
| **バンド「幅からの概算」ボタン** | 非表示 | 非表示 | **表示** | **表示** |
| **バンド下部 1コマ/対角バッジ** | 1コマ表示 | 1コマ＋対角表示 | 非表示 | 非表示 |
| **縁に重ねる本数 / 折返コマ数** | 表示 (縁重ね本数・**本**) | 非表示 | **表示** (折り返しのコマ数・**コマ**) | **表示** (折り返しのコマ数・**コマ**) |
| **側面の編みひも加算** | **表示** | 非表示 | **表示** | 非表示 |
| **折り返し加算 (片側)** | 表示 | 表示 | 表示 | 表示 |
| **加算余裕値の単位ラベル** | `コマ` | `コマ` | **`要尺`** | **`要尺`** |

### 1.3 四つ畳み編みセクションとブラウザ前回値保存（localStorage）

四つ畳み編みのコマ寸法と要尺は、ユーザー固有のゲージ値であるため、ブラウザに自動保存されます。
- **保存キー名**:
  - `cb_knot_calc_size` : コマ寸法 (mm)
  - `cb_knot_calc_len` : コマ要尺 (mm)
  ※ `knot-calc` および `knot45-calc` とキー名を統一しており、サイト全体で相互に共有されます。
- **値決定の優先順位**:
  1. **URL引数（API）**: `cb_knot_size`, `cb_knot_len` があれば最優先で反映し、localStorage も更新。
  2. **ブラウザ保存値（localStorage）**: 過去にユーザーが入力・計算した値があれば優先復元。
  3. **規定初期値**: 保存値がなければ **寸法 20.0 mm / 要尺 60.0 mm** を適用。

> [!IMPORTANT]
> **APIで指定しない場合の扱いとテスト時の注意点**
> URLパラメータで `cb_knot_size` や `cb_knot_len` を指定せずに `size-call` を開いた場合、過去に四つ畳み関連ツールを操作したことのあるブラウザ環境では、**規定初期値（20/60）ではなく、そのブラウザに保存されているユーザーの前回値が優先して読み込まれます**。
> そのため、規定初期値（20.0mm / 60.0mm）の動作をテストする際は、**シークレットウィンドウを使用するか、ブラウザの開発者ツールコンソールで `localStorage.clear()` を実行してからアクセスしてください**。

### 1.4 バンド幅からの概算ボタン仕様
四つ畳み編み選択時、バンド設定セクションに表示される「幅からの概算」ボタンをクリックすると、すき間を無視してバンド幅のみを基準に、knot系共通の計算式でコマ要尺とコマ寸法を自動算出します：
$$\text{コマ要尺} = \text{バンド幅} \times 0.98 \times 6.43 + \text{バンド幅} \times 0.7$$
$$\text{コマ寸法} = \text{バンド幅} \times 0.95 \times 2.236 + \text{バンド幅} \times 0.2$$
- 計算結果は直ちに `localStorage` に保存されます。
- コマ寸法を変更しても、バンド幅への逆反映は行われません（2つのセクションは独立）。

---

### 1.5 加算余裕値の要尺換算連動
- **四角・北欧編み**: 1単位の長さ $= (\text{bandWidth} + \text{bandGap}) / 10\text{ cm}$
- **四つ畳み編み**: 1単位の長さ $= \text{knotLen} / 10\text{ cm}$（コマ要尺基準）
四つ畳み編み選択時は、コマ要尺の変更や「幅からの概算」ボタン押下に伴い、`cm / ○ 要尺` の cm 値が自動再計算されます。

---

### 1.6 目標サイズセクション
- スマホの縦画面表示で右端の「+10」ボタンが切れるのを防ぐため、目標横幅・目標奥行・目標高さのすべてで **「-0.1」および「+0.1」ボタンを削除** しています（`-10, -1, [入力], +1, +10` の5ボタン構成）。
- UI上の入力単位は **センチメートル (cm)** ですが、「概算を開始する」ボタン押下時に各電卓の仕様に合わせて **10倍のミリメートル (mm)** に自動変換されて転送されます。

---

### 1.7 外部電卓へのパラメータ転送仕様（「概算を開始する」押下時）

各電卓へ引き渡すURLクエリパラメータのルールは以下の通りです：

#### 1. square 選択時 $\to$ `https://labo.com/CraftBand/sharing/square-calc/`
- `cb_model=square`
- `cb_mode` (out / in)
- `cb_w`, `cb_d`, `cb_h` (mm単位)
- `cb_band`, `cb_gap` (mm単位)
- `cb_add` (折り返しコマ数)
- `cb_rim` (縁に重ねる本数)
- `cb_lap` (側面の編みひも加算コマ数)

#### 2. square45 選択時 $\to$ `https://labo.com/CraftBand/sharing/square45-calc/`
- `cb_model=square45`
- `cb_mode` (out / in)
- `cb_w`, `cb_d`, `cb_h` (mm単位)
- `cb_band`, `cb_gap` (mm単位)
- `cb_add` (折り返しコマ数)

#### 3. knot 選択時 $\to$ `https://labo.com/CraftBand/sharing/knot-calc/`
- `cb_model=knot`
- `cb_mode` (out / in)
- `cb_w`, `cb_d`, `cb_h` (mm単位)
- `cb_knot_size` (コマ寸法 mm)
- `cb_knot_len` (コマ要尺 mm)
- `cb_rim` (折り返しのコマ数)
- `cb_add` (縁の加算要尺数)
- `cb_lap` (側面の編みひも加算要尺数)
- **※ `cb_band` と `cb_gap` は除外されます。**

#### 4. knot45 選択時 $\to$ `https://labo.com/CraftBand/sharing/knot45-calc/`
- `cb_model=knot45`
- `cb_mode` (out / in)
- `cb_w`, `cb_d`, `cb_h` (mm単位)
- `cb_knot_size` (コマ寸法 mm)
- `cb_knot_len` (コマ要尺 mm)
- `cb_rim` (折り返しのコマ数)
- `cb_add` (縁の加算要尺数)
- **※ `cb_band` と `cb_gap` は除外されます。**
- **※ `cb_lap` は斜め編みのため除外されます。**
