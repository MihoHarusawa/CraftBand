# knot45-calc ツール仕様書 & テスト報告書

本ドキュメントは、WordPress上で動作する `knot45-calc`（斜め四つ畳み編みサイズ計算ツール・斜め45度立ち上げ）の個別仕様、計算ロジック、およびテスト検証結果をまとめたものです。
全体共通のAPI規格については、ルートディレクトリの [`api_specification.md`](../api_specification.md) を参照してください。

## 📖 1. ツール固有仕様

### 1.1 基本構造と仕上がりサイズ（対角線方向 √2倍）
- **編み方**: 四つ畳み編み（斜め45度立ち上げ）。
- **3方向 $\sqrt{2}$ 倍の幾何学的特性**:
  斜め四つ畳み編みでは、コマの辺方向ではなく対角線方向がバスケットの幅・奥行・高さ方向になります。そのため、仕上がりサイズは3方向ともに $\sqrt{2}$ （約1.4142倍）を乗算して算出します：
  - 横幅 (cm) $= W \times \text{コマ寸法(cm)} \times \sqrt{2}$
  - 奥行 (cm) $= D \times \text{コマ寸法(cm)} \times \sqrt{2}$
  - 高さ (cm) $= H \times \text{コマ寸法(cm)} \times \sqrt{2}$ （折り返しコマ数 $F$ は含まない）
- **コマ寸法とコマ要尺**:
  - コマ寸法: 初期値 20.0 mm
  - コマ要尺: 初期値 60.0 mm
  - 参考バンド幅: コマ寸法 $\div 2.236$

### 1.2 ひも長計算モードの確定計算式
底面の縦コマ数を $D$、横コマ数を $W$、側面のコマ数を $h = H + F$（高さ＋折り返し）とします。
- $min = \min(W, D)$ （縦・横コマ数の小さい方）
- $diff = |W - D|$ （縦・横コマ数の差の絶対値）

1. **対角線同一長 (`cb_same_len=2`)**:
   $$\text{コマ数} = 4h + 2min - 1$$
   $$\text{ひも長} = \text{コマ数} \times \text{コマ要尺} + \text{縁の加算} \times 2$$
2. **四方同一長 (`cb_same_len=1`)**:
   $$\text{コマ数} = \text{対角線同一長コマ数} + (diff - 1)$$
   $$\text{ひも長} = \text{対角線同一長ひも長} + (diff - 1) \times \text{コマ要尺}$$
   - 正方形底 ($W=D, diff=0$) の場合、$(diff - 1) = -1$ となり、例外的に **四方同一長 < 対角線同一長** となります。
   - 長方形底 ($diff \ge 2$) の場合、四方同一長 $\ge$ 対角線同一長 となります。
3. **最適長 (`cb_same_len=0`)**:
   各配置位置 $k = 1 \dots W+D$ で異なる最適長を計算します。
   - 増加部 ($k = 1 \dots min$): $4h + 2(k - 1)$
   - 中央部 ($k = min + 1 \dots min + diff$, $diff$本): 対角線同一長コマ数 ($4h + 2min - 1$)
   - 減少部 ($k = min + diff + 1 \dots W + D$): $4h + 2(k' - 1)$ （$k'$ は末尾からの逆順番号）
   - 各ひも長 = $\text{コマ数} \times \text{コマ要尺} + \text{縁の加算} \times 2$

> [!NOTE]
> **底編みが正方形にならないケース（角欠け）の注記表示**
> 縦のコマ数 $D$ と横のコマ数 $W$ の大きい方の $1/2$ より、側面のコマ数 $h = H + F$（高さ＋折り返し）が小さい場合（$h < \max(W, D) / 2$）、小さいぶんだけ底編みの角が欠け、底編みが正方形になりません。
> 四方同一長 (`cb_same_len=1`) および対角線同一長 (`cb_same_len=2`) の計算式は底編みが正方形であることを前提とした数値であるため、上記条件（$h < \max(W, D) / 2$）で「四方同一長」または「対角線同一長」が選択された場合は、カットリストの最終行（合計必要長の行の後）に **`注: 正方形の底編みの場合の同一長です`** と表示します（展開図はそのまま角が欠けた状態で描画されます）。

### 1.3 展開図Canvasの仕様
- **側面外枠**: $H + F$ の高さで青色実線描画。
- **側面高さ表示**: 底面長方形の上角と底編み正方形がクロスする右側（右上側面エリア）に白背景バッジで `高さ Hコマ (+折返 Fコマ)` を表示。
- **折り返し点線**: $F > 0$ の場合のみ、高さ $H$ 位置にオレンジ色点線を描画し、ヘッダーに注記を表示。
- **底面矩形と中央線**:
  - 底面長方形を赤色太線で描画。
  - 底の中央線（短辺を含む直角二等辺三角形と、その角をつなぐ斜め線による Y字＋逆Y字ライン）を赤色の細い線で描画。
  - 対角線同一長選択時は中心斜め線を両端まで延長。
- **コマの描画**: 縁の青線にかかっている半円は編めないため非表示（底面や側面の合わせ目にかかる半円は立体化でつながるためそのまま描画）。

### 1.4 ブラウザ前回値保存（localStorage）仕様と優先順位
- **保存キー名**:
  - `cb_knot_calc_size` : コマ寸法 (mm)
  - `cb_knot_calc_len` : コマ要尺 (mm)
  ※ `knot-calc` および `size-call` と共通キーで同期。
- **優先順位**:
  1. **URLクエリパラメータ（API）**: 最優先適用＆localStorage更新。
  2. **ブラウザ保存値（localStorage）**: 前回値があれば優先復元。
  3. **規定初期値**: 保存値がない場合、**寸法 20.0 mm / 要尺 60.0 mm** を適用。

> [!IMPORTANT]
> **APIで指定しない場合の扱いとテスト時の注意点**
> URLパラメータで `cb_knot_size` や `cb_knot_len` を指定せずにアクセスした場合、以前に本ツールまたは `knot-calc` / `size-call` を操作したブラウザでは、**規定初期値（20/60）ではなく、そのブラウザに保存されているユーザーの前回値が優先して読み込まれます**。
> そのため、デフォルト動作テスト（TC-01 等）で規定の初期値（20.0mm / 60.0mm）に基づいた計算結果を検証する際は、**シークレットウィンドウ（InPrivateブラウズ）を使用するか、ブラウザの開発者ツールで `localStorage.clear()` を実行してからアクセスしてください**。

### 1.5 受け付けるURLクエリパラメータ
| パラメータ名 | 型 | 説明 | 初期値 |
| :--- | :--- | :--- | :--- |
| `cb_model` | 文字列 | `knot45` (推奨)。不一致時は処理をスキップ。 | - |
| `cb_knot_size`| 数値 (mm)| コマ寸法。片方指定時は要尺を自動補完。 | `20.0` (保存値優先) |
| `cb_knot_len` | 数値 (mm)| コマ要尺。片方指定時は寸法を自動補完。 | `60.0` (保存値優先) |
| `cb_w` | 数値 (mm)| 横幅ターゲット寸法。対角寸法基準で適合。 | - |
| `cb_d` | 数値 (mm)| 奥行ターゲット寸法。対角寸法基準で適合。 | - |
| `cb_h` | 数値 (mm)| 高さターゲット寸法。0.5刻み。 | - |
| `cb_mode` | 文字列 | 適合モード (`near`, `in`, `out`) | `near` |
| `cb_same_len`| 整数 (0-2)| ひも長モード (0:最適長, 1:四方同一長, 2:対角線同一長) | `0` |
| `cb_rim` | 整数 (コマ)| 折り返しコマ数 (側面のコマ数に加算) | `0` |
| `cb_add` | 数値 (コマ)| 縁の加算コマ数 (両端に加算 $\times 2$) | `3.0` |
| `cb_band` | 数値 (mm)| 参考バンド幅入力欄への反映値 | `寸法 / 2.236` |
